<h1 align="center"><strong>OpenRPC</strong></h1>

An open source implementation of JRPC2 for Xbox 360, with optimizations and buffer safety fixes.

Based on JRPC2 by [Xx jAmes t xX (XeAssert)](https://github.com/XeAssert/XDRPC)

Load `OpenRPC.xex` through DashLaunch after a compatible XBDM plugin, in the slot used by `JRPC2.xex`. JRPC2 calls and `Hdd:\JRPC.ini` are mostly supported.


Original OpenRPC contributions are licensed under [MIT](LICENSE).
